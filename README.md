## 🚀 Features

| # | Exercise | PHP Concepts |
|---|----------|-------------|
| 01 | ឈ្មោះពេញ | `ucwords()`, `strtolower()`, string functions |
| 02 | ម៉ាស៊ីនគិតលេខ | `switch`, arithmetic operators, `fmod()` |
| 03 | សីតុណ្ហភាព | `match`, type casting, math formulas |
| 04 | វិក្កយបត្រ | arrays, loops, `number_format()` |
| 05 | ពាក្យសម្ងាត់ | `preg_match()`, `strlen()`, scoring logic |
| 06 | Palindrome | `strrev()`, `str_word_count()`, regex clean |
| 07 | BMI | arithmetic, `match`, range checks |
| 08 | Gradebook | arrays, `array_sum()`, statistics |
| 09 | Search | `array_filter()`, `str_contains()`, GET/POST |
| 10 | Todo List | `$_SESSION`, CRUD operations |
| 11 | ប្តូរប្រាក់ | currency math, associative arrays |
| 12 | Validation | `preg_match()`, Regex patterns, `filter_var()` |
